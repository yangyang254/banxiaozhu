## 一、这是什么

班小助是一个面向班级场景的智能体应用：把一条格式混乱的班级群通知（含时间、地点、材料、要做什么）
换成一张结构化的通知卡片，并据此生成待办、按时提醒；同学对班级事务有疑问时，可以问它，
它只依据班委维护的班级资料作答，并给出依据条目。

本次作业交付的是**设计阶段**的成果：原型设计、概要设计、数据库设计三份文档 + 一篇博客，
不包含可运行系统。

## 四、设计要点（一句话版）

1. **字段级溯源**：每个字段都带原文出处与置信度，出处句子必须在原文里逐字出现，否则该字段置空——宁缺勿错。
2. **待办可选**：解析不直接生成待办，用户点「＋ 加入我的待办」才写入，解析与日程解耦。
3. **三级提醒**：提前 1 天 / 2 小时 / 10 分钟各一次，数据库唯一约束兜底去重，改时间即重算。
4. **有依据的答疑**：只依据班级资料作答并标注依据条目，资料里没写就直说没写。
5. **一周可交付的技术选型**：原生前端 + FastAPI 单进程 + SQLite 单文件 + 一个大模型接口，不做分布式。
